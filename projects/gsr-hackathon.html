GSR Hackathon Website

Overview

This project is a responsive website built for the GSR Hackathon, created to give participants and visitors a clear, engaging place to find event details. The site brings together schedule information, navigation, and prominent calls to action so visitors always know their next step, whether that's registering, checking the agenda, or reading the rules.

Key Features

  • Clear event information section with schedule and venue details.
  • Sticky navigation for quick access to every section of the site.
  • Prominent call-to-action buttons guiding visitors to register or learn more.
  • Fully responsive layout that adapts across desktop, tablet, and mobile.

Tools

  • HTML and CSS with Flexbox and Grid for layout.
  • WordPrees

My Contribution

I was responsible for structuring the page layout and implementing the responsive design so the site would look clean and usable on any screen size. I also worked on making the navigation and call-to-action elements clear and easy to follow for first-time visitors.
